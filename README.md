# Yankı 21 · 21 Günlük Farkındalık Yolculuğu

Evde, iş yerinde ve arkadaş ortamında sana söylenen sözleri fark etmen, altındaki asıl niyeti görmen ve enerjine olumlu mu olumsuz mu etki ettiğini izlemen için bir web uygulaması. Telefon (iOS, Android) ve bilgisayarda çalışır, ana ekrana uygulama olarak eklenebilir.

- `src/app.html` – uygulamanın kaynağı
- `index.html` – PWA sürümü (`./build.sh` ile üretilir)
- Veriler yalnızca cihazın tarayıcısında saklanır.

GitHub Pages ile yayınlamak için: Settings → Pages → Branch seç → kök klasör.
